# Changelog

## 1.0.1 — 2026-11-06

### Fixed

- Задачи без времени остаются активными до конца выбранного дня.
- Повреждённые даты и посторонние поля больше не попадают в сохранённое состояние.

### Added

- Автоматическая проверка синтаксиса и тестов в GitHub Actions.
- Документ с архитектурой, результатами аудита и границами масштабирования.

## 1.0.0 — 2026-11-06

- Добавлены создание, редактирование, выполнение и удаление задач.
- Добавлены сроки, фильтры и индикация просроченных задач.
- Реализованы локальное сохранение, подтверждение удаления и отмена действия.
- Добавлены адаптивный интерфейс, анимации и тесты бизнес-логики.
